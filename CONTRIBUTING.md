# Contributing

Thank you for improving HackIT Monitor.

1. Create a focused branch and keep unrelated formatting changes out of it.
2. Add or update tests when backend behaviour changes.
3. Run `python -m pytest`, `ruff check .`, `npm run lint`, and `npm run build` before opening a pull request.
4. Never include credentials, event participant data, or generated cache files in a commit.

Please describe the user-visible change and any deployment or configuration impact in the pull request.
